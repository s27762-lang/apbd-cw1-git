# APBD - Ćwiczenie 1: Git

Prosta aplikacja konsolowa napisana w C#, która wyświetla komunikat powitalny i oblicza sumę liczb z tablicy.
Program wykorzystuje klasy Greeting oraz StatisticsHelper.

## Uruchomienie

Aby uruchomić program, należy mieć zainstalowany .NET SDK i wykonać w katalogu projektu polecenie:

dotnet run
